# LulliaCare 项目介绍

## 项目背景

孕产期和育儿早期常伴随身份变化、睡眠不足、关系压力与孤独感。很多情绪并不到医疗诊断程度，却缺少低门槛、低压力、可持续的表达空间。LulliaCare 希望把“先被理解”放在产品入口，再把个人表达自然连接到同境社区。

## 产品目标

1. 让用户无需暴露真实身份即可开始表达。
2. 用不同陪伴角色适配不同的交流偏好。
3. 在保障安全的前提下，把一次性对话变成连续陪伴。
4. 帮助用户从私密倾诉过渡到可控的社区连接。
5. 明确 AI 的能力边界，不把陪伴包装成诊断或治疗。

## 核心用户旅程

```text
首次打开
  → 匿名初始化
  → 选择当前阶段与状态标签
  → 选择陪伴角色
  → 开始 AI 对话
  → 获得行动建议
      ├── 整理成社区草稿 → 用户编辑确认 → 匿名发布
      └── 推荐同境小组 → 围观或加入 → 轻量互动
  → 在个人中心查看发布、身份和 AI 记忆
```

## 主要模块

### 匿名初始化

设备首次访问后获得匿名身份与访问令牌。真实设备标识只用于后端身份映射，不直接出现在社区内容中。

### AI 陪伴

三种角色服务不同交流偏好：

- 知心闺蜜：更自然、口语化的共情陪伴；
- 过来人：强调经验感与生活化回应；
- 咨询师：提供更结构化的梳理，但不进行医疗诊断。

### 匿名社区

用户可以浏览、搜索和发布内容。AI 可以将对话整理为草稿，但发布权始终在用户手中。

### 同境小组

小组强调“相似处境”而不是公开社交。围观模式允许用户先只读，降低直接加入群聊的压力。

### 个人与记忆管理

个人中心承载匿名身份、我的内容与 AI 记忆透明化能力。用户可以查看或清除跨会话记忆。

## 当前范围

当前版本聚焦 MVP 核心闭环。正式账号系统、评论、收藏、图片内容审核与大规模搜索基础设施仍在后续规划中。
