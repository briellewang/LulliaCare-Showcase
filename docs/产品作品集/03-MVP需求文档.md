# LulliaCare MVP 需求文档（公开版）

## 1. MVP 目标

验证用户是否愿意完成以下行为链路：

```text
选择状态标签
  → 与 AI 连续对话
  → 接受发帖或小组建议
  → 进入匿名社区或小组
  → 继续表达或互动
```

如果用户愿意从私密倾诉进入匿名共鸣互动，说明核心机制具备继续投入价值。

## 2. 核心假设

### 用户假设

有情绪或经验分享需求的孕产期用户，常常不是没有表达欲，而是不知道怎么说、担心暴露和害怕被评价。

### 方案假设

匿名身份与 AI 表达辅助可以降低首次表达成本；相似处境匹配比泛内容推荐更容易带来高质量回应。

### 价值假设

真实同伴回应会让用户从一次性 AI 聊天进入持续的社区关系，并提高再次表达和回访意愿。

## 3. MVP 范围

| 模块 | 需求 |
|---|---|
| 状态标签 | 首次进入选择 1-3 个阶段或困扰标签 |
| 匿名身份 | 生成化名、头像标识和匿名编号 |
| AI 对话 | 多角色陪伴，识别表达意图与风险 |
| 行动建议 | 在适当时机建议发帖、浏览或进入小组 |
| 社区 | 列表、详情、搜索、标签筛选 |
| AI 草稿 | 从对话生成标题、正文和推荐标签，用户确认后发布 |
| 同境小组 | 推荐、围观、加入、发言和轻回应 |
| 个人中心 | 匿名身份、我的内容、隐私和记忆控制 |

## 4. 非目标

本期不以以下能力作为重点：

- 好友列表和通讯录绑定；
- 泛社交私聊；
- 复杂评论和楼中楼；
- 完整关系链；
- 大规模推荐算法；
- 商业化功能；
- AI 自动替用户发布。

## 5. 核心流程

### 发帖流程

1. 用户完成一段对话；
2. AI 判断内容是否适合分享；
3. 用户主动选择“整理成匿名帖子”；
4. 系统生成可编辑草稿；
5. 用户修改标题、正文、图片与标签；
6. 系统完成内容安全检查；
7. 用户确认发布；
8. 发布成功后可查看详情或返回对话。

### 小组流程

1. AI 识别共鸣需求；
2. 展示 1-3 个相似处境小组；
3. 用户查看匹配理由、氛围和规则；
4. 用户选择匿名加入、编辑开场白或先围观；
5. 加入后可以发言或进行轻回应；
6. 收到回应后继续表达或次日回访。

## 6. 验收原则

- 用户明确知道内容是否会公开；
- AI 生成内容必须可编辑和取消；
- 高风险内容不能进入普通发布或推荐流程；
- 失败、空状态、网络异常均有明确反馈；
- 前台不暴露真实身份；
- 核心漏斗事件可以被记录和分析。
