# 隐私与安全说明

## 产品边界

LulliaCare 是情绪支持与社区连接产品，不提供医疗诊断、处方、治疗或紧急救援。遇到紧急危险时，用户应联系当地紧急服务或专业机构。

## 数据最小化

- 前台使用匿名昵称、匿名号和头像标识；
- 设备标识只用于身份映射，不作为社区公开资料；
- 公开演示使用虚构数据，不包含真实用户对话；
- API Key、数据库、上传文件和本地环境配置不进入公开仓库。

## AI 安全

- 输入先进行安全分级；
- 高风险和紧急表达不进入普通角色回复；
- 内容审核按消息、小组资料、AI 生成文本和帖子发布等场景区分；
- 用户可以查看并清空跨会话记忆；
- AI 生成的社区草稿必须由用户编辑或确认后发布。

## 公开仓库检查清单

- [ ] 不包含 `.env` 和真实密钥；
- [ ] 不包含真实用户、聊天或上传文件；
- [ ] 截图中的账号、地址和标识已脱敏；
- [ ] 演示视频仅使用测试数据；
- [ ] 文档不承诺诊断或治疗效果；
- [ ] 对第三方素材和字体保留必要署名。

## 漏洞反馈

如果发现可能泄露身份、绕过安全分流或暴露密钥的问题，请不要在公开 Issue 中粘贴敏感数据。可先通过仓库维护者的 GitHub 主页联系并提供最小复现信息。
